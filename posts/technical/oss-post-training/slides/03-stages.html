Every RL stage runs GRPO or GSPO. All but RLHF filter prompts by learnability, keeping only those the policy can still learn from; the rest is stage-specific, such as truncated IS or mean-only advantages.

Serial rather than one mixed RL run over all environments, given our compute budget: an order that worked, not one shown to be optimal. Each stage starts from the previous checkpoint; details in Rufus-Air: An Open LLM Post-Training Recipe (arXiv 2609.29421), §3.
